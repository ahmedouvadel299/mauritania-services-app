# منصة الخدمات الموريتانية — تطبيق Flutter (مرحلة المصادقة)

## المحتوى في هذه الحزمة
شاشات: اختيار نوع الحساب → إدخال الهاتف → OTP → إكمال البيانات، مربوطة فعليًا بـ Supabase (ليست واجهات فارغة).

## طريقة الرفع إلى GitHub (بدون Terminal)
1. أنشئ مستودع (Repository) جديد فارغ على github.com باسم مثلاً `mauritania-services-app`.
2. من صفحة المستودع اضغط **Add file → Upload files**.
3. اسحب كل محتويات هذا المجلد (بما فيها المجلد المخفي `.github`) وارفعها، ثم اضغط **Commit changes**.
   - تنبيه: بعض المتصفحات لا ترفع الملفات المخفية مثل `.gitignore` بالسحب المباشر — إذا لم تظهر، أنشئها يدويًا عبر **Add file → Create new file** والصق نفس المحتوى.

## إضافة المفاتيح السرية (بدون كتابتها في الكود)
1. في صفحة المستودع: **Settings → Secrets and variables → Actions → New repository secret**.
2. أضف Secret باسم `SUPABASE_URL` بقيمة رابط مشروعك.
3. أضف Secret ثانٍ باسم `SUPABASE_ANON_KEY` بقيمة الـ anon key.

## تشغيل البناء
1. اذهب لتبويب **Actions** في أعلى صفحة المستودع.
2. سترى Workflow باسم "Build App" يعمل تلقائيًا بعد الرفع (أو اضغط "Run workflow" لتشغيله يدويًا).
3. بعد اكتمال البناء (٥-١٠ دقائق) ستجد ملف APK جاهزًا للتحميل تحت "Artifacts" في نفس صفحة التشغيل — يمكنك تثبيته مباشرة على أي هاتف Android للتجربة.

## ملاحظة عن iOS
بناء نسخة iOS يتطلب حساب Apple Developer (99$/سنة) وشهادات توقيع؛ سنضيف هذه الخطوة في مرحلة لاحقة عندما يصبح التطبيق جاهزًا للاختبار الفعلي على iPhone.
